    Tantangan Pembuka 🎯

    Apersepsi: Hitung Tanpa Kalkulator!

    Pak Dengklek — guru matematika legendaris — meletakkan kalkulatornya di lemari, lalu menulis di papan tulis:

    1001 × 1001 = ?

    “Tiga detik!” katanya, lalu ia menuliskan jawabannya dalam sekejap. 🪄

    🎯 Tebak cepat: manakah hasil 1001 × 1001?

    👆 Pilih salah satu jawaban…
    🪄 Rahasia Pak Dengklek: 1001 = 1000 + 1, jadi 1001² = (1000 + 1)² dan bentuk (a + b)² punya pola yang bisa dihitung di kepala! Hari ini kita akan menguasai pola-pola ajaib ini, memakainya untuk kuadrat raksasa, lalu membaliknya untuk memfaktorkan. 🚀
    💡 Jembatan ke materi: identitas itu seperti “jalan pintas terbukti” — sekali hafal polanya, perkalian panjang jadi hitungan kepala, dan jalan pintas yang sama bisa dibalik untuk memfaktorkan. Angka besi bukan soal kekuatan, tetapi soal strategi!

    Materi 1a

    Identitas #1: Selisih Kuadrat

    📜 Perjanjian Matematika (Identitas)

    Identitas = kesamaan yang selalu benar untuk nilai a dan b apa pun. Ia adalah “jalan pintas yang sudah dibuktikan” — kita tinggal memakainya!

    a² − b² = (a + b)(a − b)

    🔍 Bukti: dari Mana Pola Ini Muncul?

    Klik tombolnya — kita buka identitasnya pelan-pelan dengan distributif:

    Langkah 1: kalikan tiap suku: (a + b)(a − b) = a·a + a·(−b) + b·a + b·(−b)
    Langkah 2: rapikan: = a² − ab + ab − b² — perhatikan −ab dan +ab berjomblo! 👀
    Langkah 3: −ab + ab = 0 — keduanya saling melenyapkan! Sisa: a² − b² ✅ Terbukti!
    💡 Kata kuncinya: bentuk (suku + suku)(suku − suku) yang sama persis — suku tengahnya dijamin hilang. Inilah wajah yang harus kamu kenali!

    ✨ Contoh Kilat

    (x + 3)(x − 3) = x² − 9
    a = x, b = 3 → cukup kuadratkan keduanya!
    (2x + 5)(2x − 5) = 4x² − 25
    a = 2x → a² = 4x²; b = 5 → b² = 25.
    (10x + 7y)(10x − 7y) = 100x² − 49y²
    Dua variabel pun sama saja.
    ⚠️ Awas jebakan: (x + 3)(x − 3) ≠ x² − 3. Yang dikuadratkan adalah 3 (jadi 9), bukan tetap 3!
    Materi 1b

    Identitas #2: Kuadrat Sempurna

    📜 Dua Kembar: Tanda Plus & Minus

    a² + 2ab + b² = (a + b)²   a² − 2ab + b² = (a − b)²

    Tanda pada suku tengah (2ab) ikut masuk ke dalam kurung.

    🖼️ Bukti Visual: Model Luas

    Persegi bersisi (a + b) kita potong menjadi 4 bagian. Jumlah luas keempatnya = luas persegi besar:

    a
    b
    a
    a²
    ab
    b
    ab
    b²
    Persegi besar bersisi (a + b) → luasnya (a + b)².
    Empat potongan luasnya: a² + ab + ab + b² — ada DUA persegi panjang ab!
    Jadi (a + b)² = a² + 2ab + b² ✅ — bukan a² + ab + b²! Dua ab itu berasal dari dua potongan persegi panjang. 🔑

    ✨ Contoh Kilat

    (x + 4)² = x² + 8x + 16
    Suku tengah: 2·x·4 = 8x.
    (x − 6)² = x² − 12x + 36
    Tanda minus hanya menyengat suku tengah.
    (3x + 2)² = 9x² + 12x + 4
    a = 3x, b = 2 → 2·3x·2 = 12x.
    ⚠️ Kesalahan paling populer: (x + 5)² ≠ x² + 25. Yang benar: x² + 10x + 25 — jangan buang 2ab-nya!
    🎯 Cara mengingat: “Kua-Dua-Tua” — Kuadrat pertama, Dua kali hasil kali, Tua (kuadrat) terakhir: a², 2ab, b².

    Superpower 🦸

    Kuadrat Raksasa Tanpa Kalkulator

    🧠 Strategi Jujur: Dekatkan ke Angka Gampang

    Rahasia Pak Dengklek: geser angkanya sedikit agar menjadi 100, 1000, atau 10 — lalu biarkan identitas bekerja. 1001 = 1000 + 1 → bentuk (a + b)²!

    Ubah bentuk: 1001² = (1000 + 1)² — sekarang a = 1000, b = 1.
    Pasang identitas: (a + b)² = a² + 2ab + b² → 1000² + 2(1000)(1) + 1²
    Hitung tiap bagian: 1.000.000 + 2.000 + 1 — semuanya hitungan kepala!
    Jumlahkan: 1.000.000 + 2.000 + 1 = 1.002.001 ✅ Kuadrat raksasa selesai dalam 5 detik! 🎉

    🐢 Sekarang Giliran 999²

    Ubah bentuk: 999² = (1000 − 1)² — bentuk (a − b)².
    Pasang identitas: a² − 2ab + b² → 1.000.000 − 2.000 + 1
    Hati-hati urutan: kurang dulu, baru tambah: 1.000.000 − 2.000 = 998.000, lalu + 1 = 998.001 ✅
    ⚠️ Jebakan klasik: (1000 + 1)² ≠ 1000² + 1² = 1.000.001. Hasil itu kekurangan 2.000! Suku tengah 2ab wajib ikut — ingat “Kua-Dua-Tua”.
    Trik Lanjutan ⚡

    Perkalian Cepat ala Selisih Kuadrat

    ✂️ 102 × 98? Pakai Identitas #1!

    Dua angka yang jauh dari 100 sama banyak (100+2 dan 100−2) adalah pasangan sempurna untuk (a + b)(a − b):

    Ubah bentuk: 102 × 98 = (100 + 2)(100 − 2)
    Pasang identitas selisih kuadrat: = 100² − 2² — suku tengah otomatis lenyap!
    Hitung: 10.000 − 4 = 9.996 ✅ Selesai tanpa mengalikan bersusun!

    🎯 51² dan 49 × 51 — Dua Wajah Sekaligus

    51² = (50 + 1)²
    = 2.500 + 2(50)(1) + 1 = 2.500 + 100 + 1
    = 2.601 ✅
    49 × 51 = (50 − 1)(50 + 1)
    = 50² − 1² = 2.500 − 1
    = 2.499 ✅ — satu kurangnya dari 2.600? Bukan! Perhatikan polanya.
    MAKIN DEKAT KE 100 · 10 · 1000 → MAKIN GAMPANG! 🎯
    💡 Pola yang bisa langsung dipakai: (100 + k)² = 10.000 + 200k + k²  dan  (100 + k)(100 − k) = 10.000 − k². Contoh: 107² = 10.000 + 1.400 + 49 = 11.449.

    Identitas Dibalik 🔁

    Memfaktorkan Kuadrat Sempurna

    📖 Balik Arah Identitas

    Kemarin kita mengalikan (a + b)² = a² + 2ab + b². Sekarang arahnya dibalik: melihat bentuk a² + 2ab + b² dan mengembalikannya menjadi (a + b)².

    a² ± 2ab + b² = (a ± b)²

    🚦 3 Cek Wajib (seperti pemeriksaan satpam!)

    1️⃣ Suku pertama kuadrat?
    x² → akarnya x (itu a).
    2️⃣ Suku terakhir kuadrat?
    9 = 3² → akarnya 3 (itu b).
    3️⃣ Suku tengah = 2·a·b?
    2 · x · 3 = 6x — harus sama persis dengan suku tengahnya.
    ✅ Lolos 3 cek? Tulis (a + b)² — tandanya mengikuti tanda suku tengah!
    Contoh: x² + 6x + 9. Cek 1: suku pertama x² = (x)² → a = x ✔
    Cek 2: suku terakhir 9 = 3² → b = 3 ✔
    Cek 3: suku tengah seharusnya 2·x·3 = 6x — dan bentuknya memang +6x ✔
    Jadi x² + 6x + 9 = (x + 3)² 🎉 — tanda + pada 6x ikut masuk kurung.
    Naik Level 📈

    Kuadrat Sempurna dengan Koefisien

    🧪 9x² + 12x + 4 — Tiga Cek Tetap Sama

    Cek 1: 9x² = (3x)² → a = 3x ✔ (ingat: 9 = 3²)
    Cek 2: 4 = 2² → b = 2 ✔
    Cek 3: 2 · 3x · 2 = 12x — cocok dengan suku tengah ✔
    Jadi 9x² + 12x + 4 = (3x + 2)² 🎉
    ➖ Versi minus: 4x² − 20x + 25
    Cek: (2x)² = 4x² ✔, 5² = 25 ✔, 2·2x·5 = 20x ✔ — suku tengahnya minus, jadi = (2x − 5)².
    🔢 Bilangan kuadrat sahabatmu:
    1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144 — hafalkan! Mereka adalah “wajah” b untuk cek 2.
    ⚠️ AWAS — tidak semua lolos! x² + 6x + 8: cek 1 ✔ (x), cek 2 gagal karena 8 bukan kuadrat. Bentuk ini BUKAN kuadrat sempurna — jangan dipaksakan jadi (x + 3)² (itu hasilnya x² + 6x + 9). Untuk bentuk seperti ini kita perlu senjata baru: model luas di Materi 4! 🔜
    💡 Trik cepat menolak: jika suku tengah ≠ 2·(akar₁)·(akar₂), atau suku terakhir bukan kuadrat — bukan kuadrat sempurna. Lanjut ke model luas!

    Memfaktorkan ax² + bx + c dengan Konsep Luas

    🤔 Masalahnya

    x² + 7x + 12 — bukan kuadrat sempurna (12 bukan kuadrat, dan 2·x·√12 ≠ 7x). Bagaimana memfaktorkannya?

    💡 Ide besar: bentuk (x + p)(x + q) adalah luas persegi panjang bersisi (x + p) dan (x + q)! Kita cukup membalik: menyusun persegi panjang yang luasnya x² + 7x + 12, lalu membaca sisinya.

    🧩 Lab Model Luas: faktorkan x² + 7x + 12 — klik tombol untuk mengisi kotak luas satu per satu!

    x
    +4
    x
    x²
    4x
    +3
    3x
    12
    👆 Tekan tombol untuk mulai mengisi model luas…
    x² + 7x + 12 = (x + 4)(x + 3) 🎉

    🪜 Langkah Emas Model Luas

    1️⃣ Cari pasangan ajaib m dan n: harus m × n = c (12) dan m + n = b (7). Kandidat: 3 & 4 → 3·4=12 ✔, 3+4=7 ✔
    2️⃣ Belah suku tengah: 7x = 3x + 4x — pakai pasangan tadi.
    3️⃣ Susun kotak luas: pojok x², kanan 4x, bawah 3x, sisa pojok 12.
    4️⃣ Baca sisi-sisinya: faktornya (x + 4)(x + 3) — cek dengan distributif ✅
    💡 Kenapa 7x dibelah jadi 3x + 4x? Karena di kotak, sisa pojok otomatis berupa 4 × 3 = 12. Pasangan (m, n) harus mengalikan ke c DAN menjumlahkan ke b — itulah syarat kotaknya pas!
    Tanda Minus Masuk 🌡️

    Model Luas dengan Tanda Negatif

    🧊 x² − 3x − 10: Ada Area yang Dicoret

    Sekarang c = −10 (negatif) dan b = −3. Artinya pasangan m, n harus m × n = −10 (tanda berbeda!) dan m + n = −3. Kandidat: (−5) × 2 = −10 ✔ dan −5 + 2 = −3 ✔

    x
    −5
    x
    x²
    −5x
    +2
    2x
    −10

    Area merah = “area dicoret” (nilai negatif) — dihitung mengurangi.

    Susun kotak: kolom x dan −5; baris x dan +2.
    Empat areanya: x², −5x, 2x, −10. Jumlahkan: x² + 2x − 5x − 10
    Gabungkan suku tengah: 2x − 5x = −3x → total x² − 3x − 10 — cocok! ✅
    Jadi x² − 3x − 10 = (x − 5)(x + 2) 🎉

    ⚖️ Jika a ≠ 1: FPB Dulu, Model Luas Kemudian!

    2x² + 10x + 12 — semua suku habis dibagi 2:

    Keluarkan FPB 2: 2x² + 10x + 12 = 2(x² + 5x + 6)
    Sekarang a = 1! Cari pasangan: m·n = 6, m+n = 5 → 2 & 3 ✔
    Jadi = 2(x + 2)(x + 3) 🎉 — jangan lupa FPB-nya menunggu di depan!
    CARI PASANGAN → BELAH SUKU TENGAH → SUSUN KOTAK → BACA SISI! 🖼️

    Kesimpulan Hari Ini

    1️⃣ Dua Identitas Istimewa

    a² − b² = (a + b)(a − b)  ·  a² ± 2ab + b² = (a ± b)² — terbukti lewat distributif dan model luas. Ingat “Kua-Dua-Tua”!

    2️⃣ Kuadrat Raksasa? Gampang!

    Dekatkan ke 10/100/1000 lalu pakai identitas: 1001² = (1000+1)² = 1.002.001, 102 × 98 = 10.000 − 4 = 9.996. Tanpa kalkulator! 🦸

    3️⃣ Faktor Kuadrat Sempurna

    Tiga cek wajib: suku pertama kuadrat ✔, suku terakhir kuadrat ✔, suku tengah = 2·a·b ✔ → tulis (a ± b)².

    4️⃣ Bukan Kuadrat Sempurna? Model Luas!

    Cari m·n = c dan m+n = b, belah suku tengah, susun kotak, baca sisi: x² + 7x + 12 = (x + 4)(x + 3). Ada FPB? Keluarkan dulu!
