    Materi 1 dari 2

    Kenapa a ≠ 1 Itu Istimewa?

    ✅ Bekal Lama: a = 1

    Untuk x² + px + q cukup cari dua bilangan yang dikalikan = q dan dijumlahkan = p:

    x² + 5x + 6 = (x + 2)(x + 3)

    2 × 3 = 6 ✔  ·  2 + 3 = 5 ✔

    😅 Sekarang: a ≠ 1

    Suku pertama punya koefisien: 3x² + 10x + 8. Tebakan (3x + …)(x + …) banyak sekali kemungkinannya — faktor dari 3 ada 2 pilihan, faktor dari 8 ada 4 pilihan, ditambah bolak-balik tanda!

    Menebak terus = buang waktu. Kita butuh trik yang langsung menunjuk pasangan yang tepat.

    🧪 Bukti: Menebak Itu Melelahkan

    Mari kita uji tebakan satu per satu untuk 3x² + 10x + 8. Klik tombolnya!

    Tebakan 1: (3x + 1)(x + 8) = 3x² + 25x + 8 ✘ — suku tengahnya 25, bukan 10!
    Tebakan 2: (3x + 8)(x + 1) = 3x² + 11x + 8 ✘ — meleset 1 saja… tetapi tetap salah!
    Tebakan 3: (3x + 4)(x + 2) = 3x² + 10x + 8 ✔ ketemu — setelah 3 kali percobaan.
    Bayangkan kalau a = 12 dan c = 35 — kombinasi tebakannya bisa puluhan! Karena itu, pelajari triknya di slide berikutnya ➜
    Trik Utama 🔑

    Trik Kali–Jumlah: Mulai dari a × c

    Empat langkah yang selalu berhasil untuk ax² + bx + c dengan a ≠ 1:

    1️⃣ KALI UJUNG

    Kalikan a × c — koefisien pertama kali konstanta terakhir.

    2️⃣ CARI PASANGAN

    Cari dua bilangan p dan q dengan p × q = a × c dan p + q = b.

    3️⃣ PECAH TENGAH

    Ganti bx menjadi px + qx — bentuknya kini menjadi 4 suku.

    4️⃣ KELOMPOKKAN

    Faktorkan dua-dua, keluarkan faktor bersamanya — selesai! ✅

    🎯 Misi langkah 1–2: untuk 6x² + 11x + 4, sudahkah kamu hitung a × c = 6 × 4 = 24? Klik pasangan yang dikalikan = 24 dan dijumlahkan = 11!

    Klik sepasang bilangan…
    3 × 8 = 24 ✔  dan  3 + 8 = 11 ✔ — pasangannya 3 dan 8! 🎉

    🎬 Demo Lengkap: 6x² + 11x + 4

    Langkah 1 — KALI: a × c = 6 × 4 = 24
    Langkah 2 — CARI: dari misi di atas: 3 × 8 = 24 dan 3 + 8 = 11 ✔
    Langkah 3 — PECAH: 6x² + 11x + 4 = 6x² + 8x + 3x + 4
    Langkah 4 — KELOMPOKKAN: 2x(3x + 4) + 1(3x + 4) — faktor (3x + 4) muncul dua kali!
    Keluarkan (3x + 4): 6x² + 11x + 4 = (3x + 4)(2x + 1) ✅
    💡 Kenapa trik ini pasti berhasil? Hasil kali (px + q)(rx + s) memiliki suku tengah psx + qrx — dan pasangan yang dipilih Trik Kali–Jumlah menjamin jumlahnya tepat b. Jadi bukan sulap, murni logika!
    Pemeriksa Kilat 🔍

    Cek Silang: Bukti 3 Detik

    Setelah mendapat (px + q)(rx + s), periksa tiga posisi: p·r (harus = a), q·s (harus = c), dan jumlah silang p·s + q·r (harus = b). Klik kandidat pasangan di bawah untuk mengujinya!

    ⚡ Tips Tanda Instan

    🟢 c positif, b positif

    Kedua faktor bertanda +. Contoh: 2x² + 7x + 6 = (2x + 3)(x + 2)

    🔴 c positif, b negatif

    Kedua faktor bertanda −. Contoh: 2x² − 7x + 6 = (2x − 3)(x − 2)

    🟠 c negatif

    Tanda berbeda; bilangan yang besarnya lebih besar mengikuti tanda b. Contoh: 6x² + x − 12 = (2x + 3)(3x − 4) — silangnya +9 dan −8, karena 9 lebih besar maka b bertanda +.

    🧹 Jangan Lupa: FPB Dulu!

    Sebelum memakai trik, keluarkan FPB bila ada: 6x² + 15x + 9 = 3(2x² + 5x + 3) — angkanya menjadi kecil, hitungan jadi ringan!

    Contoh Berjenjang 🎬

    Tiga Contoh, Tiga Rasa

    Klik tombol langkah untuk membuka pembahasannya satu per satu.

    Contoh A · Tanda minus (c positif, b negatif)

    2x² − 7x + 6

    Langkah 1–2: a × c = 2 × 6 = 12. Karena c positif dan b negatif → kedua bilangan negatif: −3 dan −4 (−3 × −4 = 12 ✔, −3 + (−4) = −7 ✔)
    Langkah 3: pecah → 2x² − 3x − 4x + 6
    Langkah 4: kelompokkan → x(2x − 3) − 2(2x − 3)
    Hasil: (2x − 3)(x − 2) — cek silang: 2 × 1 = 2 ✔ · (−3)(−2) = 6 ✔ · −4x − 3x = −7x ✔

    Contoh B · c negatif (tanda berbeda)

    6x² + x − 12

    Langkah 1–2: a × c = 6 × (−12) = −72. c negatif → tanda berbeda. Cari pasangan: 9 × (−8) = −72 dan 9 + (−8) = 1 ✔ (9 lebih besar → b bertanda +)
    Langkah 3: pecah → 6x² + 9x − 8x − 12
    Langkah 4: kelompokkan → 3x(2x + 3) − 4(2x + 3)
    Hasil: (2x + 3)(3x − 4) — cek silang: 2 × 3 = 6 ✔ · 3 × (−4) = −12 ✔ · −8x + 9x = x ✔

    Contoh C · FPB Dulu!

    6x² + 15x + 9

    Perhatikan: 6, 15, 9 semuanya habis dibagi 3 → keluarkan FPB: 3(2x² + 5x + 3)
    Di dalam kurung: a × c = 2 × 3 = 6; pasangan 2 dan 3 (2 × 3 = 6 ✔, 2 + 3 = 5 ✔)
    Pecah & kelompokkan: 3(2x² + 3x + 2x + 3) = 3[x(2x + 3) + 1(2x + 3)]
    Hasil: 3(2x + 3)(x + 1) — jangan lupa menulis angka 3-nya! Jawaban tanpa 3 berarti belum lengkap. ✅

    Materi 2 dari 2

    Pembagian Aljabar: Faktorkan Dulu! ✂️

    🤔 Masalah Baru

    (3x² + 10x + 8) ÷ (x + 2) = ?

    Pembaginya dua suku — cara bagi-per-suku tidak bisa dipakai. Tetapi perhatikan: bentuk di pembilang persis contoh Materi 1! Artinya…

    Berpikir terbalik: ? × (x + 2) = 3x² + 10x + 8 — kita sedang mencari berapa tanda tanya itu.
    Dari Materi 1: 3x² + 10x + 8 = (3x + 4)(x + 2)
    Maka ? × (x + 2) = (3x + 4)(x + 2) → jelas terlihat ? = 3x + 4!
    Kesimpulan: jika pembagi adalah salah satu faktor pembilang, jawabannya langsung kelihatan. Mari kita mesinkan dengan pencoretan ⬇️

    ✂️ Mesin Pencoret

    Contoh 1
    (3x² + 10x + 8) ÷ (x + 2)
    = (x + 2)(3x + 4) ÷ (x + 2)
    = 3x + 4 🎉
    Faktorkan dengan Trik Kali–Jumlah: 3x² + 10x + 8 = (3x + 4)(x + 2). Faktor (x + 2) di atas dan di bawah saling menghilangkan karena (x + 2) ÷ (x + 2) = 1.

    ⚠️ Syarat Mencoret: Penyebut ≠ 0

    Mencoret artinya membagi — dan pembagi tidak boleh nol! Jadi mencoret (x + 2) hanya sah jika x + 2 ≠ 0, artinya x ≠ −2. Biasakan menuliskan syarat ini di pekerjaanmu — guru matematika pasti tersenyum 😊

    Praktik Mesin Pencoret ✂️

    Tiga Level Mesin Pencoret

    Level 1 · Trinomial Sederhana (a = 1)
    (x² − 5x + 6) ÷ (x − 2)
    = (x − 3)(x − 2) ÷ (x − 2)
    = x − 3 🎉
    x² − 5x + 6: cari dua bilangan kali 6, jumlah −5 → −2 dan −3, jadi (x − 2)(x − 3). Coret (x − 2) dengan syarat x ≠ 2.
    Level 2 · FPB Dulu, Lalu Selisih Kuadrat
    (2x² − 8) ÷ (x + 2)
    = 2(x + 2)(x − 2) ÷ (x + 2)
    = 2x − 4 🎉
    Tiga langkah: FPB dulu → 2(x² − 4); selisih kuadrat → 2(x + 2)(x − 2); coret (x + 2) dengan syarat x ≠ −2. Sisanya 2(x − 2) = 2x − 4.
    Level 3 · Dua-duanya Difaktorkan!
    (x² − 5x + 6) ÷ (x² − 9)
    = (x − 2)(x − 3) ÷ (x + 3)(x − 3)
    = (x − 2) / (x + 3) 🎉
    Pembilang: (x − 2)(x − 3). Penyebut: selisih kuadrat (x + 3)(x − 3). Yang kebetulan sama hanya (x − 3); (x + 3) tidak memiliki pasangan, jadi tetap di penyebut. Syarat: x ≠ 3 dan x ≠ −3.
    FAKTORKAN DULU → CORET YANG SAMA → TULIS SISANYA ✂️
    💡 Urutan berpikir pembagian: FPB → pola spesial (selisih kuadrat / kuadrat sempurna) → Trik Kali–Jumlah. Begitu faktor muncul, pembagian selesai sekali coret — dan jangan lupa syarat penyebutnya ≠ 0!

    Rangkuman

    Kesimpulan Hari Ini

    1️⃣ Trik Kali–Jumlah

    Untuk ax² + bx + c dengan a ≠ 1: kali a×c → cari pasangan (kali = a×c, jumlah = b) → pecah suku tengah → kelompokkan. Contoh: 6x² + 11x + 4 = (3x + 4)(2x + 1)

    2️⃣ Cek Silang & Tips Tanda

    Periksa: p·r = a, q·s = c, silang p·s + q·r = b. Tips: c positif → tanda sama; c negatif → tanda beda. Dan selalu FPB dulu bila ada!

    3️⃣ Pembagian = Faktorkan + Coret

    Jika pembagi adalah faktor pembilang, bagi dengan mencoret: (3x² + 10x + 8) ÷ (x + 2) = 3x + 4 ✂️

    4️⃣ Syarat: Penyebut ≠ 0

    Mencoret hanya boleh jika faktor yang dicoret tidak nol: mencoret (x + 2) berlaku untuk x ≠ −2. Tulis syaratnya setiap kali!
